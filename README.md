# 🍕 Pizza Sales Data Analytics Dashboard – PostgreSQL & Power BI

This project demonstrates an end-to-end **data analytics and business intelligence workflow**, starting from raw pizza sales data and **SQL analysis in PostgreSQL** to an interactive dashboard built using **Microsoft Power BI**.

The project focuses on analyzing sales performance, customer ordering patterns, revenue trends, pizza categories, sizes, and top-performing products to generate meaningful business insights.

## 🚀 Project Workflow

The project follows a practical analytics pipeline:

1️⃣ **Raw Pizza Sales Dataset**
2️⃣ **Data Import into PostgreSQL**
3️⃣ **Data Cleaning & Validation using SQL**
4️⃣ **SQL-Based Data Analysis**
5️⃣ **Power BI Data Modeling & DAX Measures**
6️⃣ **Interactive Pizza Sales Dashboard**

---

## 🗄️ Data Preparation & SQL Analysis

The raw dataset was imported into **PostgreSQL** for structured data storage and analysis.

Key activities included:

✅ Importing CSV data into PostgreSQL
✅ Validating data types and records
✅ Handling data inconsistencies
✅ Writing SQL queries for business analysis
✅ Calculating sales and order-related KPIs
✅ Analyzing daily and monthly sales trends
✅ Identifying top and bottom-performing pizzas

PostgreSQL was used as the primary database for querying and analyzing the sales data before visualization in Power BI.
